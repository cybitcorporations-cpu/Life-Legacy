# GTTW PROJECT INT'L — MVP

A front-end MVP structure for GTTW: Your Life. Your Wealth. Your Legacy. Beyond Time.

## Included
- Responsive landing page
- Wealth Path concept and daily task
- Legacy dashboard preview
- Marketplace preview
- Future Lab / Project Phoenix positioning
- Genesis founder story
- Registration modal prototype
- Basic interaction/toast feedback

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
